# Distance Calculator

This is the code for finding the distance between two points

## **How to make the code run**

First, run the Python program. You would be asked to enter the coordinates of x1 y1 x2 y2. Enter the values of coordinate when asked

## **Input neeeded**

-x1
-y1
-x2
-y2

## **Output**

x1: 8
y1: 9
x2: 2
y2: 5
The Distance between the two points is: 7.21
